# 🧩 基础（Foundations）

> 基础路线是**回查手册，不是强制起点**。七个模块覆盖学习世界模型与空间智能所需的数学与机器学习最小集。主线读到卡壳时，回来补对应的一页，然后直接跳回去。

## 怎么用这一部分

1. 先做[从这里开始](/docs/start-here/)里的**先修自查清单**。全部打勾就直接进主线，不必读这里。
2. 哪一项没打勾，就只读对应的那一页。每页都有：**最小知识集**、**何时回查**（哪些主线模块会用到）、**最佳外部资源**、**自查**标准。
3. 达到自查标准就回主线。这里不设作业，能读懂主线对应章节的公式和代码就够了。

| 模块 | 你会补上什么 | 主要服务的主线模块 |
|---|---|---|
| [线性代数](./linear-algebra.mdx) | 向量空间、特征值与稳定性、SVD、最小二乘、齐次坐标 | 路线 A 03、路线 B 02 / 06 |

## 按背景推荐的补课顺序

- **来自 NLP / 大语言模型**：通常缺计算机视觉和强化学习。先读[计算机视觉](./computer-vision.mdx)，再读[强化学习](./reinforcement-learning.mdx)。
- **来自计算机视觉**：通常缺概率建模和强化学习。先读[概率论](./probability.mdx)，再读[强化学习](./reinforcement-learning.mdx)。
- **来自机器人 / 控制**：通常缺现代深度学习。先读[深度学习](./deep-learning.mdx)，再读 [Transformer](./transformers.mdx) 和 [PyTorch](./pytorch.mdx)。
- **刚学完一门机器学习课**：按表格顺序从上往下读，大约两周业余时间。

## 通用参考书（免费）

- **《Mathematics for Machine Learning》**（Deisenroth et al., [mml-book.github.io](https://mml-book.github.io/)）：线代与概率。
- **《Probabilistic Machine Learning: An Introduction》**（Kevin Murphy, [probml.github.io/pml-book](https://probml.github.io/pml-book/)）：概率视角的机器学习。
- **《Dive into Deep Learning》**（[d2l.ai](https://d2l.ai/)）：带可运行代码的深度学习教材，有[中文版](https://zh.d2l.ai/)。
- **《Computer Vision: Algorithms and Applications》**（Richard Szeliski, [szeliski.org/Book](https://szeliski.org/Book/)）：计算机视觉。
- **《Reinforcement Learning: An Introduction》**（Sutton & Barto, [incompleteideas.net/book](http://incompleteideas.net/book/the-book-2nd.html)）：强化学习。
