# Linear Algebra（线性代数）

> 本页是**回查手册**，不是完整课程。学到主线模块卡壳时回来补对应小节即可。

## 最小知识集

- **向量空间与基底**：状态向量 $s_t$、观测向量 $o_t$ 都是向量空间中的点；换基 = 换坐标系。
- **矩阵分解**：特征分解理解线性动力学的模式（$s_{t+1} = A s_t$ 中 $A$ 的特征值决定稳定/发散）；SVD 用于降维与最小二乘。
- **线性最小二乘**：Kalman filter 的更新步本质上是递归加权最小二乘。
- **坐标变换与齐次坐标**：路线 B 的相机模型 $K[R|t]$、刚体变换全靠它。
