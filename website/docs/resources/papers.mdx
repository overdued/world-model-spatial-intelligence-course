# Papers

A curated canon of the literature this course teaches from. Filter by **concept** (the part of the world-model stack a paper belongs to) and by **level**:

- **Foundation** — the classics everything else assumes (Kalman 1960, VAE, PointNet, ORB-SLAM…)
- **Must Read** — the papers you should actually read in full to complete a track
- **Advanced** — deep dives and recent frontier work for after the core modules
