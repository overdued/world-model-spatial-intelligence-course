# 论文

本课程所依据的精选文献。可以按**概念**（论文属于世界模型技术栈的哪一部分）和**难度**筛选：

- **基础**：其他一切工作都默认你知道的经典（Kalman 1960、VAE、PointNet、ORB-SLAM……）
- **必读**：要完成一条路线，真正应该完整读完的论文
- **进阶**：学完核心模块之后的深入阅读与近期前沿工作
