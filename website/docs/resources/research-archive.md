# 研究资料库

打磨好的学习路线背后，是一个研究资料库：本课程由这些调研笔记、结构化元数据和设计文档综合而来。它公开存放在仓库里，每一个课程设计决策都可以追溯到来源。

## 资料库里有什么

| 路径 | 内容 |
| --- | --- |
| [`courses/`](https://github.com/overdued/world-model-spatial-intelligence-course/tree/main/courses) | 11 门已索引大学课程各自的调研目录：收集的链接、lecture 清单和状态记录（材料本身不再分发） |

## 基本原则

- **可追溯**：如果某个模块说"CIS6280 是这样讲 X 的"，资料库里就应该有对应的依据。
- **精选，不搬运**：资料库记录的是链接、结构与分析，第三方 slides 和论文从不重新托管。
- **持续更新**：资料库以追加为主。当领域有新进展（新的视频世界模型、新的 VLA 发布），新材料会先进入调研，再进入课程。
