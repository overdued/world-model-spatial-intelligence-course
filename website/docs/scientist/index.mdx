## 为什么是这个顺序

这条路线遵循**真实的研究流程**，而不是教科书目录：

1. **状态的基础**（a01–a03）：世界模型到底是什么，观测与状态的区别，以及你将要超越、也会借鉴的经典状态空间基线。
2. **表征与动力学**（a04–a08）：先学一个值得在其中做预测的潜空间，再走一遍 RSSM 谱系：World Models 2018 → PlaNet → Dreamer。
3. **使用模型**（a09–a11，含 a10b）：规划（MPC / CEM / MPPI）、视频尺度的预测、可以实时交互的世界模型，以及用策略闭环。
4. **信任模型**（a12）：OOD、漂移与评估。一个无法审计的世界模型是一种负担。
5. **毕业项目**（a13）：亲手构建一个，把状态 / 转移 / 动作 / 评估都显式写出来。

## 完成标准

当你能在一个新环境上复现 Dreamer / TD-MPC 级别的系统，并按 Lab 10 的规范为它写出标准化评估报告时，这条路线就完成了。职业方向：*世界模型研究员 / 研究工程师*。

不适合你？并行的[空间与具身工程师](/docs/spatial/)路线构建的是系统而不是模型：地基相同，出口不同。
