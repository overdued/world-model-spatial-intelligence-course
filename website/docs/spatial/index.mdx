## 为什么是这个顺序

这条路线遵循空间系统**真实的工程流程**：

1. **感知与表征**（b01–b05）：先打几何基础（相机、深度、点云），再进入现代神经表征（NeRF、Gaussian Splatting、动态 4D）。
2. **状态估计**（b06–b08）：滤波与因子图，在真实基准上跑 SLAM / VIO，以及持久的空间记忆。
3. **在空间中行动**（b09–b12）：可供性、导航，以及从机器人世界模型一直到 VLA 与世界-动作模型。
4. **毕业项目**（b13）：感知 → 状态估计 → 规划，端到端地在基准上评估。

## 完成标准

当你能搭起一个完整的空间智能系统（感知、估计、规划），并在公开基准（EuRoC 级别）上完成评估时，这条路线就完成了。职业方向：*空间 AI 工程师 / 机器人感知工程师*。
