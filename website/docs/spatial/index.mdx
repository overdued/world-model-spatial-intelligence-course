# 👷 Spatial & Embodied Engineer

<TrackRoadmap track="spatial" />

## Why this order

The track follows the **real engineering pipeline** of a spatial system:

1. **Perception & representation** (b01–b05) — geometry first (cameras, depth, point clouds), then the modern neural stack (NeRF, Gaussian Splatting, dynamic 4D).
2. **State estimation** (b06–b08) — filtering and factor graphs, SLAM/VIO on real benchmarks, and persistent spatial memory.
3. **Acting in space** (b09–b12) — affordances, navigation, and robot world models up to VLA and world-action models.
4. **Capstone** (b13) — perception → state estimation → planning, evaluated on a benchmark, end to end.

## Exit criteria

You are done with this track when you can stand up a complete spatial-intelligence system — perceive, estimate, plan — and evaluate it on a public benchmark (EuRoC-class). Career narrative: *Spatial AI Engineer / Robotics Perception Engineer*.

Not your track? The parallel [World Model Scientist](/docs/scientist/) track builds the models themselves — same foundations, different exit.
