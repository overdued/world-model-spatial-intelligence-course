# 🧩 Foundations

> Foundations is a **reference manual, not a mandatory starting point**. Seven modules cover the minimal math and machine learning you need for world models and spatial intelligence. When a main-track module loses you, read the matching page here, then jump straight back.

## How to use this track

1. Start with the **prerequisite checklist** in [Start Here](/docs/start-here/). If you can tick every box, skip this track and go straight to the main tracks.
2. For each box you can't tick, read only the matching page. Every page has a **minimal knowledge set**, a **when to consult** table (which main-track modules use it), the **best external resources**, and a **self-check**.
3. Once you meet the self-check, go back to the main track. There are no assignments here. Being able to read the formulas and code in the main-track modules is enough.

## The seven modules

| Module | What you'll fill in | Main-track modules it serves |
|---|---|---|

| [Transformers](./transformers.mdx) | Attention, positional encoding, autoregressive and masked modeling, ViT | Track A 04 / 10, Track B 12 |

| [Reinforcement Learning](./reinforcement-learning.mdx) | MDPs, the Bellman equation, values and policies, model-free vs model-based | Track A 08 / 09 / 11 |

## Suggested order by background

- **Coming from NLP / LLMs**: usually missing computer vision and RL. Read [Computer Vision](./computer-vision.mdx), then [Reinforcement Learning](./reinforcement-learning.mdx).
- **Coming from computer vision**: usually missing probabilistic modeling and RL. Read [Probability](./probability.mdx), then [Reinforcement Learning](./reinforcement-learning.mdx).
- **Coming from robotics / control**: usually missing modern deep learning. Read [Deep Learning](./deep-learning.mdx), then [Transformers](./transformers.mdx) and [PyTorch](./pytorch.mdx).
- **Just finished an ML course**: read top to bottom in table order, about two weeks part-time.

## General references (free)

- ***Mathematics for Machine Learning*** (Deisenroth et al., [mml-book.github.io](https://mml-book.github.io/)): linear algebra and probability.
- ***Probabilistic Machine Learning: An Introduction*** (Kevin Murphy, [probml.github.io/pml-book](https://probml.github.io/pml-book/)): machine learning from the probabilistic view.
- ***Dive into Deep Learning*** ([d2l.ai](https://d2l.ai/)): a deep learning textbook with runnable code.
- ***Computer Vision: Algorithms and Applications*** (Richard Szeliski, [szeliski.org/Book](https://szeliski.org/Book/)): computer vision.
- ***Reinforcement Learning: An Introduction*** (Sutton & Barto, [incompleteideas.net/book](http://incompleteideas.net/book/the-book-2nd.html)): reinforcement learning.
