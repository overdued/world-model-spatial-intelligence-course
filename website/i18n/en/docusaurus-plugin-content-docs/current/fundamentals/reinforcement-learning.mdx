# Reinforcement Learning

> This page is a **reference manual**. To borrow CIS6280's official disclaimer: **this is not an RL course**. You only need enough vocabulary to follow "how world models serve decision-making."

## Minimal knowledge set

- **MDP**: the five-tuple $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$; a POMDP is its partially observable version (expanded in Track A Module 02).
- **Bellman equation**: $V^\pi(s) = \mathbb{E}_\pi[r + \gamma V^\pi(s')]$ — the recursive definition of the value function.
- **Value / Policy**: the relationship among $V(s)$, $Q(s,a)$, and $\pi(a \mid s)$; TD-MPC's "model + value function" combination rests on this distinction.
- **Model-free vs model-based**: everything in this course sits on the model-based side; understanding the contrast is enough.
- **Policy gradients and actor-critic**: Dreamer trains an actor-critic in imagination; you only need to know the structure, not to derive it.
