## Course Description

研究生课程，讲授计算机图形学、计算机视觉与机器学习中使用的几何概念与算法，目标是让学生能够阅读和复现顶级 CV/CG 会议的最新 3D 论文（非工业就业导向）。先修：线性代数（熟练）、多元微积分、概率与数值方法、强编程能力（Linux / Python / NumPy / PyTorch）。评分：HW0 5% + HW1–3 各 20% + Final Project 35% + 参与加分 5%，无期末考。

## Major Topics

- Geometry Basics（1D/2D/3D 几何、变换、几何的计算机存储、全局几何）
- 3D Reconstruction（Single-image to 3D、Multiview 3D）
- 3D Recognition（Classification、Detection、Segmentation、6D Pose Estimation）
- 3D Geometry Processing（Point Cloud Processing、Learning-based Mesh Processing）
- Part-based 3D Understanding（Part-based Generative Model、Zero-shot 3D Understanding、Mobility、Human and Hand Pose）
- 3D Shape Collection（Pairwise Correspondence、Collection Correspondence）

## Relevance to World Models

中高：3D 重建与生成式 3D 是空间世界模型的表示基础，但无动力学/预测内容。

## Relevance to Spatial Intelligence

高：几何 + 学习结合的 3D 理解全链条（重建→识别→部件理解→对应关系）。

## Relevance to Embodied AI

中：6D 位姿、人体/手姿态与 mobility 分析与操作相关，但无机器人实验。

## What We Can Learn from This Course

- "几何基础 → 重建 → 识别 → 处理 → 部件理解 → 集合对应"的递进组织方式，适合作为 spatial intelligence 知识线骨架；
- Hao Su 组在 part-based 3D 理解（mobility / affordance 方向）的选题视角，可补其他课程缺失的"可操作部件/affordance"环节。
