## Course Description

（以下为官方公开描述的中文摘要；英文原文快照见 `syllabus/course_description_SCI-6512.txt`）

成年人一生约有三分之一时间在工作。课程探讨：随着组织采用传感器、数字平台和 AI 驱动的分析，工作场所正演变为持续捕捉行为模式的复杂、数据丰富的环境；设计师能否利用这些工具重新构想更能支持人类绩效与福祉的工作环境。

课程研究空间条件——光照（light）、声音（sound）、温度（temperature）、亲生命性（biophilia）与布局（layout）——如何在各类工作环境（传统办公室、居家办公、工作室、教室、服务与医疗空间）中塑造认知功能、创造力、舒适度与沟通。学生将使用问卷（surveys）、传感器（sensors）与计算工具（包括机器学习）收集、分析和可视化数据，量化空间因素对工作结果的影响。课程强调"微干预"（micro-interventions）：学生设计并评估真实环境中的小规模改变。

实践为核心：学生完成一系列练习（exercises）与迷你项目（mini-projects），逐步构建到最终项目（final project）。同时批判性地审视智能环境（intelligent environments）的伦理、社会与技术影响。

面向建筑（architecture）、城市设计（urban design）、MDes、MDE 项目学生；非 GSD 学生欢迎；建议但不强制要求编程经验。

## Major Topics

（来源：官方课程描述页，该课未公开逐周 lecture 标题，以下为主题主线）

- Spatial Intelligence 定义与框架：空间条件（light / sound / temperature / biophilia / layout）与人类认知、创造力、舒适、沟通的关系
- Sensors 与环境数据采集：传感器、数字平台、AI-driven analytics、问卷（surveys）
- Intelligent Environments（智能环境）：伦理、社会与技术影响的批判性审视
- Multimodal Data：多模态数据的收集、解读、分析与可视化
- Machine Learning：用 ML 量化空间因素对工作结果的影响、预测空间设计对健康/行为/福祉的影响
- Human-Space Interaction（人-空间交互）：human-building interaction、evidence-based intervention 设计与评估
- Micro-interventions：真实环境中的小规模设计干预
- Future of Work：新兴 AI 趋势与混合办公（hybrid work）模式下的工作环境再设计

## Course Structure

官方页面未公布逐周安排。从描述可还原的结构主线：

1. **理论/背景**：空间条件与人类结果（cognitive functioning, creativity, comfort, communication）的关系；工作环境类型学。
2. **数据方法**：用 surveys、sensors、计算工具（含 ML）收集、分析、可视化多模态数据。
3. **实践递进**：exercises → mini-projects → final project，逐步构建。
4. **设计干预**：micro-interventions 的设计与实证评估（evidence-based）。
5. **批判反思**：智能环境的伦理、社会、技术影响；AI 趋势与 hybrid work 下的未来工作空间设计。

## Relevance to World Models

**低-中**。课程不涉及生成式世界模型、视频预测或环境动力学建模；但其核心方法——用传感器多模态数据 + ML 构建"空间条件 → 人类行为/福祉结果"的预测模型——本质上是一种统计意义上的环境-行为预测模型，可视为 human-centered 的弱世界模型视角。对理解"world model 在建成环境中的应用场景"有参考价值。

## Relevance to Spatial Intelligence

**高**。这是课程的核心定位：以人为中心的 Spatial Intelligence（human-centered spatial intelligence）。覆盖空间条件感知（sensors）、多模态数据、智能环境、人-空间交互、空间对认知与行为的影响——是 Architecture / Smart Environments 语境下 Spatial Intelligence 的直接教学案例。

## Relevance to Embodied AI

**低-中**。无机器人实验、无 3D 重建、无导航/操作任务；但 human-space interaction、具身化的环境感知（人体在空间中的行为数据）与 Embodied AI 的环境理解有间接关联。

## What We Can Learn from This Course

- Spatial Intelligence 的一个非 CS 视角定义：设计学科语境下的"空间智能"= 用传感与数据量化空间条件对人类结果的影响，并据此设计干预。
- 完整的方法链条：multimodal data collection（sensors + surveys）→ ML 分析 → 可视化 → evidence-based micro-intervention 设计 → 评估。
- 智能环境的伦理/社会/技术批判视角，可作为课程开源内容中"负责任的空间智能"模块参考。
- 面向设计学生的低门槛 ML/数据教学组织方式（programming recommended but not required），对本课程面向跨学科学生的分层设计有借鉴意义。
